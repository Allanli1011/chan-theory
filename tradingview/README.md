# TradingView 缠论指标 (Pine Script v6 移植)

[`chan_theory.pine`](chan_theory.pine) 是本仓库 `chanlun/` Python 流水线的 TradingView 移植版，
在图表上直接绘制 **笔 / 线段 / 中枢 / 三类买卖点**，算法与 Python 版逐模块对应：

| Pine 函数 | Python 模块 | 内容 | 课程出处 |
|---|---|---|---|
| `f_merge` | `cmerge.py` | K线包含处理 (高高/低低合并) | 课17/62 |
| `f_fractals` | `fractal.py` | 顶/底分型 | 课62 |
| `f_buildBis` | `bi.py` | 笔 (走势腿跟踪, `min_dist`) | 课62/65 |
| `f_buildSegments` 等 | `segment.py` | 线段 (特征序列 + 缺口两种情况) | 课65/67 |
| `f_zhongshus` | `zhongshu.py` | 走势中枢 (公共重叠延伸 / 同级别分解) + 9段升级标记 | 课17/18/33 |
| `f_expansions` | `zhongshu.py` | 中枢扩展 (相邻重叠中枢 → 更高级别中枢) | 课29/36 |
| `f_findBsps` | `signals.py` + `macd.py` | MACD 面积背驰 + 一/二/三类买卖点 (一类点要求**趋势**背驰) + 盘整背驰单独标注 | 课17/24/27 |
| `f_classifyTrend` | `signals.py` | 走势类型 (上涨/下跌/盘整) | 课17 |

信号在**笔级别**与**线段级别**各跑一遍（线段级 = 更高级别共振确认，标签前缀"段"）。

## 安装

1. 打开 [TradingView](https://www.tradingview.com/) 任意图表，底部打开 **Pine Editor**；
2. 把 `chan_theory.pine` 全文粘贴进去；
3. 点 **Add to chart / 添加到图表**。可用 "Save" 存到自己的指标库，之后任何图表都能加载。

## 图例

- **蓝色折线** = 笔；**黄色粗折线** = 线段（末段可能未终结，会随新K线变化）；
- **橙色矩形** = 笔中枢 `[ZD, ZG]`；紫色矩形 = 线段中枢（默认关闭）；
  **红边加粗 + "↑9段升级"** = 延伸达9段、已构成更大级别的中枢（课33）；
  **紫红虚线框 + "扩展"** = 相邻中枢扩展成的更高一级中枢（课29/36，同级别分解模式下更常见）；
- **绿色标签**（K线下方）= 一买/二买/三买；**红色标签**（K线上方）= 一卖/二卖/三卖，
  悬停可见触发原因与背驰力度比；**淡色小标"盘背买/盘背卖"** = 盘整背驰提示
  （背驰但无趋势前提，不属于三类买卖点，课24/27）；
  **大标签前缀"段"** = 线段级信号（更高级别共振，可靠性更高）；
- 右上角面板：**整体走势**（全窗口内所有中枢依次抬高=上涨 / 依次降低=下跌 / 否则盘整，
  长窗口下几乎总是"盘整"，属正常）、**近端走势**（只看最后两个笔中枢的相对位置，更适合盯盘）、
  当前中枢模式、买卖点分级统计（笔/段, 含盘背计数）。

## 警报（含声音提醒）

新信号（笔级/线段级，含盘整背驰）在最近 3 根K线内确认时触发。**声音本身是
TradingView 创建警报弹窗里的开关**——Pine 脚本无法从代码里强制播放声音，只能
负责"什么时候触发"；要听到声音，警报创建后必须在同一个弹窗的"通知"栏勾选
"声音提醒"并选一个铃声。

创建方式：图表右键或点右侧闹钟图标 → **添加提醒** → "条件"选下面三者之一：

| 条件 | 触发范围 | 消息 |
|---|---|---|
| **任何 alert() 函数调用** | 全部类型（一/二/三类买卖点 + 盘整背驰） | 最详细，含具体信号名/价格/力度比 |
| **缠论: 一/二/三类买卖点** | 只有真正的三类买卖点，跳过盘整背驰噪音 | 含品种/周期/收盘价（TradingView 占位符） |
| **缠论: 盘整背驰提示(非正式买卖点)** | 只有盘整背驰提示（课24/27，非正式买卖点） | 同上 |

想要"只对真正的买卖点响铃、盘整背驰不出声"，创建一个警报选第二个条件即可；
想要两者分开用不同铃声提醒，各建一个警报、分别配置声音。

## 与 Python 版一致的理论增强

- **一类买卖点要求趋势前提**（课17/27）：背驰的关联中枢前必须有依次同向的前中枢；
  没有趋势前提的背驰单独标注为"盘背买/盘背卖"（可在设置中关闭显示）；
- **线段级信号**：以线段为走势单元、线段中枢为中枢再跑一遍完整信号逻辑；
- **9段升级**（课33）与**中枢扩展**（课29/36）标记；
- **区间套**（课27）在图上的用法：线段级"段"标签圈定大级别背驰段，其内部的笔级
  同向信号即为精确化入场点——跨周期区间套请开多个周期窗口对照（Python 版
  `interval_nest` 可自动完成）。

## 与 Python 版的差异和注意事项

1. **计算窗口**：只分析最近 `最大分析K线数` 根K线（默认 3000，当前上限 5000）。所有
   绘图对象用 `xloc.bar_time`（按各K线真实时间戳定位）而不是 `xloc.bar_index`，不吃
   Pine 的 `bar_index` 历史缓冲区，理论上没有硬性上限；5000 只是先留的保守默认值，
   想要更大窗口可以再调。TradingView 本身也按套餐限制历史K线数量；窗口起点不同可能
   使最早的一两笔与 Python 全量回算略有出入，越往后越收敛一致。
2. **MACD 一致性**：Pine 端 EMA 用"首值作种子"的递推，与 `macd.py` 的纯 numpy 回退实现
   完全一致（不是 TA-Lib 路径）；MACD柱 = `2*(DIF-DEA)`，同国内惯例。
3. **未收盘K线**：默认最后一根未收盘K线也参与计算，所以末端的笔/线段/信号会随盘中价格
   变化（这不是未来函数，只是"当下未确认"）。开启"仅在K线收盘后更新"可避免盘中跳动。
   缠论买卖点本身是**确认制**的：一个分型/笔要等右侧K线走出来才成立，历史信号不重绘。
4. **多级别**：Python 版的 `analyze_multi_level` 在 Pine 里对应"直接切换图表周期"——
   30分钟/日线/周线各开一个图表窗口即可，无需重采样。
5. **绘图对象上限**：中枢框最多画最近 120 个、买卖点标签最多最近 240 个、分型标记最近
   200 个（TradingView 每个指标 500 个对象的硬限制）。
6. 与 Python 版一样：线段采用课67特征序列有界确认，中枢默认公共重叠延伸模式；
   工程取舍的出处见仓库根目录 [FRAMEWORK.md](../FRAMEWORK.md)。
